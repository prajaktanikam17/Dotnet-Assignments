# Medical Store Billing System

## 🔹 Description

This is a Console-based Medical Store Billing System developed using C# and MySQL.
The application allows users to add medicines, generate bills, store data in a database, and fetch invoice details.

---

## 🔹 Features

* Add Customer
* Add Medicines
* Generate Bill
* Store data in MySQL database
* Fetch invoice by customer name
* Display invoice in console format

---

## 🔹 Technologies Used

* C#
* .NET Console Application
* MySQL Database

---

## 🔹 Database Tables

* Customer
* Medicine
* Bill
* BillDetails
* Sales
