# How I debugged today

Today I improved my menu-driven console application by converting the program logic into separate methods with proper parameters and return values.

I added:
- Input validation using TryParse
- Exception handling using try-catch

During debugging:
- I used breakpoints to pause execution at important lines
- I used Watch to check values of variables like choice, num, and result
- I used Step Over to move line by line
- I used Step Into to go inside methods and understand the flow

This helped me find mistakes quickly and verify that each method worked correctly.
